# Deploy AgileForge: Render API + Vercel frontend

The root `render.yaml` defines the Express API as a Render web service. The React/Vite app is a separate Vercel project. MongoDB remains the application's database; provide a reachable MongoDB connection string when Render prompts for `MONGODB_URI`.

## 1. Deploy the backend on Render

1. Push this repository to GitHub and open the Render Dashboard.
2. Choose **New → Blueprint**, connect the AgileForge repository, and select the branch to deploy. Render reads the root `render.yaml`.
3. When prompted, set `MONGODB_URI` to the connection string for your MongoDB deployment.
4. Set `CLIENT_URLS` to the Vercel frontend origin, with no path or trailing slash. Multiple exact origins can be comma-separated, for example `https://agileforge.vercel.app,https://agileforge.example.com`.
5. Deploy. Render generates `JWT_SECRET`; keep it private. `JWT_EXPIRES_IN` and `NODE_ENV` are configured in the Blueprint.
6. Once live, open `https://<your-render-service>.onrender.com/api/health`. A healthy response contains `"status":"ok"`.

The service uses Render's free web service plan. Free services can spin down while idle, so the first request after inactivity can take longer to respond. Upgrade the plan if you need an always-on API.

## 2. Deploy the frontend on Vercel

1. Import the same GitHub repository as a Vercel project.
2. Set the **Root Directory** to `frontend`.
3. Use build command `npm run build` and output directory `dist` (Vercel normally detects Vite automatically).
4. Add this environment variable in Vercel for Production and Preview as needed:

   ```text
   VITE_API_URL=https://<your-render-service>.onrender.com/api
   ```

5. Deploy or redeploy the frontend. Vite embeds `VITE_API_URL` during the build, so changing it requires a new deployment.
6. Copy the deployed Vercel origin, such as `https://agileforge.vercel.app`, into Render's `CLIENT_URLS`. If you change Render environment variables, redeploy/restart the API.

## Environment variable summary

| Where | Variable | Value |
| --- | --- | --- |
| Render | `MONGODB_URI` | MongoDB connection string |
| Render | `JWT_SECRET` | Generated by the Blueprint; keep private |
| Render | `CLIENT_URLS` | Comma-separated exact Vercel origins |
| Vercel | `VITE_API_URL` | Render API URL ending in `/api` |

Do not commit `.env` files or put database credentials or JWT secrets in Vercel's `VITE_` variables; Vite exposes those variables to the browser bundle.
